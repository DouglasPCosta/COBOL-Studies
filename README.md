## 📖 Sobre o Projeto

Este repositório foi criado com o objetivo de documentar minha jornada de aprendizado e evolução no desenvolvimento **COBOL para ambiente Mainframe**.

Aqui você encontrará exemplos práticos, exercícios, programas e estudos relacionados ao ecossistema Mainframe utilizado por grandes instituições financeiras e empresas de missão crítica.

O foco é demonstrar conceitos fundamentais da linguagem COBOL, boas práticas de programação estruturada e a integração com tecnologias amplamente utilizadas no ambiente IBM Mainframe.

---

## 🎯 Objetivos

- Aprender a linguagem COBOL na prática
- Desenvolver lógica de programação em ambiente Mainframe
- Criar programas seguindo boas práticas
- Compartilhar conhecimento com a comunidade
- Construir um portfólio voltado para Mainframe
